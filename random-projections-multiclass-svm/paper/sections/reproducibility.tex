\section*{Reproducing the results}

\texttt{python scripts/kamp\_hw3.py --datasets iris breast\_cancer wine seeds glass --legacy-seeding} reproduces the original accuracies. The study runs with \texttt{python study/run\_svm.py --datasets iris breast\_cancer wine seeds glass} and \texttt{study/run\_distortion.py} with the same \texttt{--datasets} (each stops after nine minutes by default and resumes when rerun; repeat each until it no longer prints ``rerun to resume'', because the analysis reads whatever rows are present), then \texttt{study/replicate.py}, \texttt{study/analyze.py}, and \texttt{study/figures.py}, and the 20,000-draw variance check with \texttt{study/variance\_check\_many.py}. Every result number and table in this paper is generated from the files in \texttt{results/} and \texttt{study/results/} by \texttt{paper/make\_numbers.py}. The Classes column of Table~\ref{tab:data} comes from the UCI data set pages, and a few design constants, such as the 2,000 pairs and the 133 fits per draw, are written into the text.
