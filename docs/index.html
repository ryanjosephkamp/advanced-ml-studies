I.Eyeing the Iris: four kernels, four problemsOne rule that labels a flower by the nearer class average, four kernels, and four problems on Iris: what the kernel changes, and how little the training share moves test accuracy averaged over all 13 problem–kernel pairs and the 500 random splits at each share.
  2. II.Alphabet amnesia: why a Hopfield network forgets its lettersWhy a Hopfield network built as the assignment specifies recalls none of 18 dense character bitmaps from noisy copies, and how overlap, density, and the learning rule change exact recall as more patterns are stored.
  3. III.Shape-shifting: geometry preservation with sparse random projectionsSparse random matrices shrink four to thirty features before a support vector machine: how well they keep class neighborhoods, and how one sparse draw can cost accuracy.
  4. IV.EMD for EEGEmpirical mode decomposition against plain band power on three EEG data sets: a corrected baseline, the features compared, and what the original split hid.
